อัปโหลดวิดีโอ

เลือกไฟล์จากอุปกรณ์ของคุณ ระบบจะส่งไฟล์ไปยังเซิร์ฟเวอร์ที่ตั้งค่าไว้

เลือกไฟล์วิดีโอ ไฟล์ขนาดใหญ่อาจใช้เวลาอัปโหลดนาน โปรดเปิดหน้านี้ค้างไว้

อัปโหลดเฉพาะเนื้อหาที่ถูกกฎหมาย โดยผู้ใหญ่ที่ยินยอมและมีเอกสารยืนยันอายุ/ตัวตนและสิทธิ์เผยแพร่ ควรเก็บวิดีโอใหม่เป็นส่วนตัวหรือไม่แสดงสาธารณะจนกว่าจะตรวจสอบเรียบร้อย

ก่อนเปิดใช้งานจริง

เช็กลิสต์สำหรับผู้ดูแลระบบ

  1. ตั้งค่า Bunny Stream Video Library และ Environment Variables บนเซิร์ฟเวอร์
  2. จำกัดโดเมนและสิทธิ์เข้าถึงวิดีโอให้เหมาะสม
  3. เพิ่มฐานข้อมูลและระบบบัญชีผู้ใช้/สิทธิ์ผู้ดูแล
  4. เพิ่มการตรวจสอบเนื้อหาและระบบรายงาน
  5. ใช้ signed playback หรือมาตรการป้องกันที่เหมาะสมก่อนเผยแพร่สู่สาธารณะ
รายการวิดีโออาจใช้แค็ตตาล็อกในหน่วยความจำของเซิร์ฟเวอร์ หากรีสตาร์ตแล้วรายการหาย ต้องเพิ่มฐานข้อมูลเพื่อเก็บข้อมูลถาวร
